Need help with Operator, want to report a problem, or have a suggestion? Email [operator@cybernetks.be](mailto:operator@cybernetks.be).

Support messages are reviewed as availability permits. A specific response time is not guaranteed, but providing the details below helps us investigate efficiently.

## What to include

Please include:

- the Operator version and build number;
- your iPhone or iPad model;
- your iOS or iPadOS version;
- what you expected to happen;
- what happened instead; and
- the steps that reproduce the problem, if known.

A screenshot or short screen recording can help when the issue is visual. Remove or obscure private information before attaching it.

Do not email passwords, authentication codes, or sensitive project and task content. Share only the information needed to investigate your request.

## Finding your Operator version

Open **Operator → Settings**. The version and build number appear near the top of the screen below the Operator name.

## If iCloud synchronization is not working

Check that:

1. Each device is signed in to the same Apple Account.
2. iCloud Drive is enabled for the device and Operator is allowed to use iCloud.
3. Your iCloud account has available storage.
4. Each device has a working internet connection.
5. Operator has been opened on each device and given a little time to synchronize.

If the workspace still differs between devices, contact support with the device models, operating-system versions, Operator versions, and a description of which changes are missing.

## General troubleshooting

Try these steps in order:

1. Update Operator to the latest available version.
2. Install the latest compatible iOS or iPadOS update.
3. Close and reopen Operator.
4. Restart the device.
5. Try the action again and note any message shown by the app.

If the problem continues, send the details listed above to [operator@cybernetks.be](mailto:operator@cybernetks.be).

## Before deleting or reinstalling Operator

Do not delete or reinstall Operator as an initial troubleshooting step. Workspace changes that have not synchronized to iCloud may be lost. Contact support first if you are considering either action because of a data or synchronization problem.

## Privacy questions

The [Operator Privacy Policy](/projects/operator/privacy/) is published separately alongside this support page. For privacy questions or requests, email [operator@cybernetks.be](mailto:operator@cybernetks.be).
